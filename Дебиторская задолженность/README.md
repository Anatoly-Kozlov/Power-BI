## Обзор проекта
Проект посвящён анализу дебиторской задолженности компании с фокусом на контроль просроченных долгов, их динамику и распределение по ключевым управленческим разрезам: менеджерам, клиентам и городам.

## Цели и бизнес-задачи
- оценить общий объём ДЗ и её структуру по срокам просрочки;
- контролировать долю просроченной задолженности в продажах;
- выявлять проблемных клиентов и менеджеров;
- анализировать динамику ДЗ в течение года, независимо от выбранного месяца.

## Источник данных
- Источник данных: Дебиторская задолженность.xlsx

## Модель данных

На этапе Power Query созданы справочники и настроены связи:

- **Год** — уникальные годы (используется в слайсере)
- **Месяц** — уникальные месяцы (используется в слайсере)
- **Менеджер** — уникальные менеджеры (используется в слайсере)

Модель данных построена по принципу «звезды», что обеспечивает корректную работу фильтров и мер.


### Таблица видов дебиторской задолженности
Используется для динамической компоновки мер и отображения различных типов ДЗ на графиках:
```DAX
Таблица видов ДЗ = 
DATATABLE(
    "Вид ДЗ", STRING,
    "Порядок", INTEGER,
    {
        {"без просрочки", 1},
        {"до 30 дней", 2},
        {"31-60 дней", 3},
        {"61-90 дней", 4},
        {"до 90", 5},
        {"от 91 дня", 6}
    }
)
```

### Универсальная мера для графиков
Используется совместно с таблицей Таблица видов ДЗ:
```DAX
Сумма ДЗ для графика = 
SWITCH(
    SELECTEDVALUE('Таблица видов ДЗ'[Вид ДЗ]),
    "без просрочки", SUM('ДЗ'[без просрочки]),
    "до 30 дней", SUM('ДЗ'[до 30 дней]),
    "31-60 дней", SUM('ДЗ'[31-60 дней]),
    "61-90 дней", SUM('ДЗ'[61-90 дней]),
    "от 91 дня", SUM('ДЗ'[от 91 дня]),
    "до 90", [AR_Overdue]-SUM('ДЗ'[от 91 дня]),
    BLANK()
)
```


### Таблица месяцев для оси графиков
Создана отдельная таблица для отображения всех месяцев года на помесячных графиках независимо от фильтрации месяца:

```DAX
Месяцы для оси = 
ADDCOLUMNS(
    GENERATESERIES(1, 12, 1),
    "МесяцКратко", FORMAT(DATE(2020, [Value], 1), "MMM", "ru-RU"),
    "НомерМесяца", [Value]
)
```

### Calculation Group для помесячной динамики

Для корректного отображения помесячных графиков независимо от выбранного месяца создана Calculation Group.

```DAX
CALCULATE(
    SELECTEDMEASURE(),

    ALL('Месяц'[Месяц]),
    TREATAS(
        VALUES('Месяцы для оси'[НомерМесяца]),
        'Месяц'[НомерМесяца] 
    )
)
```

## Результат
Дашборд может использоваться финансовым менеджером или руководителем отдела продаж
для оперативного контроля дебиторской задолженности, выявления рисков неплатежей
и принятия управленческих решений по работе с клиентами и менеджерами.
